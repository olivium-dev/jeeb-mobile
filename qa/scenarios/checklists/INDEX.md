# Checklist index

Use these checklists for every run. Copy them into the run evidence folder; do
not mark the source templates complete.

| Checklist | Use |
|---|---|
| [PRE-RUN.md](PRE-RUN.md) | Authorization, environment, build/store provenance, data, device, and mutation safety |
| [PER-SCENARIO.md](PER-SCENARIO.md) | Execute one scenario consistently, including OS/store boundaries, and classify its result |
| [EVIDENCE.md](EVIDENCE.md) | Capture useful proof without secrets or personal data |
| [RELEASE.md](RELEASE.md) | Smoke/regression/RC completion and GO/NO-GO |

Checkbox meaning:

- Empty box: not checked.
- Checked box in a copied run record: observed with evidence.
- N/A: must include a reason and approver; it is not equivalent to PASS.
- BLOCKED: scenario remains incomplete and cannot satisfy a release gate.
