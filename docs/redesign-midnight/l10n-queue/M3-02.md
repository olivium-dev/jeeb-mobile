## 1. `escalateAutoAttachNote`

The frozen id `dispute_auto_attach_note` (JM-060 AC1 / D53) names an
auto-attachment promise, but the note renders `escalateSubtitle` — the screen
lede about support response times, next to a paperclip glyph. Pass 1 recorded
this as deliberate ("it now carries the screen's lede copy itself") because the
same sentence was ALSO printed inside the evidence card; this lane deleted that
duplicate, so the note can now say what its id says.

Interim: `escalateSubtitle`.


is now the first thing read above the captured-clip row.
