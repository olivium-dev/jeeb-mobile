## 1. `settingsNotificationCategoryOffers`

**Why a new key rather than an edit.** The tile draws **"New offers"**
(`Jeeb Rich UI.dc.html` line 1381). The app renders `notificationCategoryOffers`
= `"Offers"` — doc-13 P1 flags this as undocumented copy drift. The key is
**shared**: `NotificationPreferencesScreen` (an M3 row) renders the same string
on its own surface, and `test/settings_screen_test.dart:157` asserts on its
value. Rewriting it would change a screen this lane does not own, so the drift
is closed with a settings-scoped key instead — the same precedent as
`settingsBecomeJeeberSubtitle` vs `becomeJeeberCardSubtitle`.

`lib/features/settings/presentation/widgets/settings_notifications_card.dart`
— the offers `_ToggleRow`, tagged `TODO(midnight): l10n-queued`.
