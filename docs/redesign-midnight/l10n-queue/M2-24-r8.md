## Why it is queued but unused

The R8 tile draws a 3px orange underline under one low-confidence word
(`tpl 493`: `border-bottom:3px solid var(--jeeb-orange)`) and its hint copy
points at that underline. **`POST /transcribe` returns only `{ audioId,
transcription }`** — no per-word confidence, no offsets
(`voice_recording_repository.dart:52-58`, `TranscriptionResult` carries `id` +
`transcript` only). So the underline is a doc-13 **Pattern-A** omission:
designed slot kept, nothing faked.

Shipping the tile's literal today would name an affordance that cannot render,
which is the same lie as drawing a fake underline. R8 therefore keeps the honest
existing key `transcriptionTapHint` (`Tap any word to fix it` — accurate: every
word IS tappable) and this key waits for the wire.
