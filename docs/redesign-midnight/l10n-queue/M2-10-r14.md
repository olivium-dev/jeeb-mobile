## New keys

### `receiptProofBadgeAt`

The tile's proof tag reads **"Proof of delivery · 9:38"**. `DeliveryReceipt`
carries no capture time (`lib/features/delivery_receipt/domain/delivery_receipt.dart`
has no such field and the gateway sends none), so `ProofPhotoHero` ships the
designed slot (`capturedAtLabel`) with `TODO(midnight): omitted, not faked` and
falls back to the plain `receiptProofBadge`. Land this key with the gateway
field, not before.

| | |
|---|---|
| **key** | `receiptProofBadgeAt` |
| **EN** | `Proof of delivery · {time}` |
| **AR** | `إثبات التسليم · {time}` |
| **description** | Overlay tag on the proof-of-delivery photo, with the time the Jeeber captured it. |
| **placeholder** | `time` — `String`, an already-formatted local time (e.g. "9:38"). |

Consumer once it exists: `proof_photo_hero.dart`, replacing the
`'$badgeText$_kBadgeSeparator$capturedAtLabel'` join (delete `_kBadgeSeparator`
with it — the separator belongs inside the localized string, since RTL wants it
placed by the translator).
