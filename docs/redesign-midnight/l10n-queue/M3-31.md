## No new key needed for the error frame — worth recording why

The error state also grew a headline slot. Rather than mint one, the existing
feature-local `ReviewsL10n.loadError` (`"Could not load reviews."` /
`"تعذّر تحميل التقييمات."`) was **promoted from body to headline**, and
`ReviewsL10n.networkError` became the optional second line — shown only for
`ReviewsFailure.network`, because on the other three failures it would repeat
the headline verbatim. Both strings already existed; neither changed.

Note that `ReviewsL10n` is a feature-local `_pick(en, ar)` shim, not ARB-backed
— only the three keys above go through `lib/l10n`. If the l10n lane wants the
whole shim migrated, that is a larger, separate item and this row did not start
it.
