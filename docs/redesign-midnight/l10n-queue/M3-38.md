# l10n queue — M3-38 diagnostics

**Nothing is queued, deliberately. Do not add ARB keys for this screen.**

`DiagnosticsScreen` is a dev-only tool behind the `Diag.enabled` build gate
(`kDebugMode || JEEB_DIAG`). Its copy is literal English by a standing decision
that predates Midnight and is recorded at its entry point —
`lib/features/settings/presentation/widgets/settings_more_card.dart:53-56`:

> Literal English strings by design — a dev tool that never ships, deliberately
> kept out of the ARB catalogs.

The restyle added five literal strings and translated none:

| String | Frame |
|---|---|
| `Reading session files…` | loading headline (the frame previously named nothing) |
| `Could not read the session folder` | error headline (frame is NEW — the throw used to degrade to the empty state) |
| `Retry, or pull the folder off the device with adb.` | error body |
| `Try again` | error retry CTA |
| `Diagnostics is off` | disabled headline, above the pre-existing notice sentence |

All five sit in the same register as the strings already on the screen
(`adb pull one-liner`, `On-device folder`, `No session files yet`), none of
which is in the catalogs either. Translating five of ~14 would be worse than
translating none.

If the standing decision is ever reversed, the whole screen moves at once —
this file is the list of what a reversal would have to cover, plus the eight
pre-existing literals in `lib/core/diagnostics/diagnostics_screen.dart`.
