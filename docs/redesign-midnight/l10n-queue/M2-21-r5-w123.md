# l10n queue — M2-21 (R5 onboarding + W1/W2/W3 walkthrough slides)

Owner lane: l10n. Do NOT edit `lib/l10n/*.arb` from this row.

Two mechanisms are in play, and the difference matters at review:

1. **Slide copy + a few chips** render the *nearest existing key* behind a
   `TODO(midnight): l10n-queued` comment, so nothing is blank.
2. **W2's identity card and two of the chips have no near key at all**
   (proper nouns, brand-new decorative labels). Those render the tile literal
   from a file-private `const` block —`WalkthroughTrustCopy` in
   `walkthrough_trust_art.dart` and `WalkthroughTrackingCopy` in
   `walkthrough_tracking_art.dart` — each tagged `TODO(midnight): l10n-queued`.
   Rendering `Verified account` where the tile says `ID-verified` would have
   made the capture un-reviewable, which is the one thing worse than a literal.
   Swapping each to `l10n.<key>` is a one-line change per site.

## ⚠️ AR RETRANSLATION FLAG (the master-plan carry-in for this row)

**Every string below is English-only today.** The shipped AR values for the six
slide-copy keys were translated against the *pass-1* copy and no longer describe
what the tile says — e.g. `onboardingSlide1Title` is `توصيل بالصوت أولًا`
("voice-first deliveries") where W1 now reads "Say what you need". Landing the
EN value changes without the AR pair would leave Arabic silently describing the
old design.

Also: the two `const` blocks render **English in both locales**. Slide 2 and
slide 3 therefore have visible untranslated runs on an Arabic device until this
queue lands. That is deliberate and recorded, not an oversight.
