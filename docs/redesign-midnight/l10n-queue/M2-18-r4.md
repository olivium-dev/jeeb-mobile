## Open question for the l10n/product owner

`giftBadge` says "included". doc-13 P1 lists the missing clause as a defect, and
the tile literal carries it — so it is restored. But the wire still does not
state whether `giftCredit` is a component of `availableBalance` or sits beside
it; the previous lane dropped the word for exactly that reason. **If the gateway
says the gift is NOT already inside `availableBalance`, this string is a lie and
must revert.** Needs one owner sentence on the `GET /v1/jeeb/wallet` contract.
