## New keys

| Key | EN | AR |
|---|---|---|
| `registrationSocialGoogleShort` | `Google` | `Google` |
| `registrationSocialAppleShort` | `Apple` | `Apple` |

**Why they exist.** doc-13 P1: the two-up social row clipped
"Continue with Google" / "Continue with Apple" to "Continue with" on *both*
pills, so the provider — the only thing separating them — was what
disappeared. The R6 tile draws the bare brand name. The full sentence stays as
the accessibility label on both pills, so nothing a screen reader announces
gets shorter.

**AR is deliberately identical.** Both ARBs already carry the latin brand name
inside the long form (`المتابعة بحساب Google`), so the short form is the same
proper noun in every shipped locale.
